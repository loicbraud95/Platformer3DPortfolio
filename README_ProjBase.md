# Plateformer 3D

## Features:
- Advanced Collisions
- Ground Test using raycasts
- InputSystem
- Checkpoint System
- Button System
- State machine for movements
- Wall Gliding
- Camera follows player
etc...

## Controls (QWERTY):
- WASD : Move around the scene
- Space : Jump (Double jump available)
- Escape : Close Game
- W : Switch to menu (WIP)
- Mouse Right Click (Hold) : Rotate camera

### Tools & libs used:

- ImGUI : https://github.com/ocornut/imgui
- Glad : https://glad.dav1d.de/
- GLFW : https://www.glfw.org/
- STBImage : https://github.com/nothings/stb
